Applying Object-Oriented Principles in Java Engineering Labs

A rigorous exploration of polymorphic sensor abstraction and concurrency safety for serial telemetry interfaces developed during senior engineering laboratory modules.

data_object SensorTelemetryManager.java
Java 21 • Concurrent ThreadPool 
public sealed class SensorTelemetryManager implements AutoCloseable {
    // Non-blocking virtual thread executor for high-frequency ADC telemetry
    private final ExecutorService dispatchQueue = Executors.newVirtualThreadPerTaskExecutor();
    
    public CompletableFuture<TelemetryPacket> pollSynchronous(final I2CDeviceBus bus) {
        return CompletableFuture.supplyAsync(() -> bus.readFrame(0x48, 16), dispatchQueue);
    }
}
